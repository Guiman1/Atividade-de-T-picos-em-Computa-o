# Atividade-de-T-picos-em-Computa-o
AV2 - ATIVIDADE I - TÓPICOS EM COMPUTAÇÃO

Documento contendo todos os principais comandos que acho necessário para utilização de Github/GitFlow

git status
(Olha todas as modificações que você fez no arquivo que ainda não foram commitadas para seu repositório.)

git push
(Permite mandar as alterações de um repositório local para um repositório remoto.)

git pull
(Contrário ao push, ele puxa todas as alterações de um repositório remoto para um local.)

git clone
(Clona um repositório para um novo diretório na sua máquina local.)

git add
(Comando usado para preparar alterações em arquivos.)

git commit
(Exibe informações sobre as modificações do arquivo.)

git commit -m "Nome"
(Commita as alterações no arquivo para o repositório, incluindo o nome das mudanças nas aspas.)

git commit --amend
(Caso as alterações de um commit ainda não foi dado push, é possível corrigir erros com o esse comando. Ele deixa fazer a edição de mensagem e depois salva.)

git branch
(Usado para gerar ramificações no repositório Git.)

git branch "Nome"
(Faz a criação do branch.)

git branch -m "NomeAntigo" "NomeNovo"
(Renomea a branch desejada do Git.)

git checkout
(Permite alternar entre as ramificações e restaurar arquivos de diferentes commits.)
